# 📊 التوثيق التفصيلي والدليل الشامل لصفحة تقرير نسب الإنجاز (Completion Percentage Page)

هذا المستند يوفر تفصيلاً كاملاً ومستقلاً لصفحة **تقرير نسب الإنجاز الشامل** (`completion-percentage`) في نظام **Quantum Build**، ويشمل بنية الملفات، نموذج البيانات (Schema)، الحسابات الرياضية، المكونات البرمجية، وآلية تصدير التقرير كملف PDF رسمي، بالإضافة إلى طرق تصحيح الأخطاء وحلها.

---

## 🎯 1. هدف الصفحة ووظيفتها الرئيسية

تعد صفحة **تقرير نسب الإنجاز** واحدة من أهم الصفحات الفنية والهندسية في نظام إدارة البناء. تُستخدم هذه الصفحة من قبل مهندسي الموقع، ومدراء المشاريع، والمطورين العقاريين لإصدار **تقرير دوري رسمي متكامل مألوف للاستخدام في قطاع التطوير العقاري والهندسي** (مكون من 8 أقسام رئيسية).

### الميزات الأساسية للصفحة:
1. **المرونة التفاعلية:** إدخال وتعديل نسب إنجاز 58 بنداً هندسياً تفصيلياً (29 بنداً للعظم + 29 بنداً للتشطيبات).
2. **الحساب الآلي للنسب:** حساب نسبة الإنجاز الفعلية الموزونة لقطاعات العظم والتشطيبات والمشروع الإجمالي بدون الحاجة لتدخل يدوية.
3. **تتبع الميزانيات والدفعات:** متابعة 9 مراحل للدفعات المالية موزعة بين المطور والمقاول الرئيسي.
4. **التوثيق البصري بالموقع:** رفع وإدارة المعرض المصور لأعمال الموقع.
5. **معاينة وطباعة رسمية:** التصدير بنقرة واحدة إلى ملف **PDF قياسي رسمي** أو صورة عالي الدقة.

---

## 📁 2. الهيكل البرمجي والملفات التابعة

تقع الصفحة والمكونات المرتبطة بها في المسارات التالية داخل المشروع:

```text
frontend/src/
├── pages/

```

## 📐 3. نموذج البيانات الشامل (`defaultCompletionData.js`)

تعتمد الصفحة على كائن بيانات (State Object) يحتوي على الأجزاء الهيكلية التالية:

### أ. البيانات التعريفية والمؤشرات المالية
- `projectType`: نوع المشروع (مثل: شقق سكنية، برج تجاري).
- `projectNumber`: رقم الكود المعتمد للمشروع (مثل: M32).
- `location`: العنوان والموقع الجغرافي.
- `unitsCount`: إجمالي عدد الوحدات.
- `reportPeriod`: الشهر أو التاريخ المالي للتقرير.
- `docRef`: الرقم المرجعي للوثيقة.
- `contractDurationMonths` & `actualDurationMonths`: مدة العقد والمدة المنقضية.
- `contractorBudget` / `developerBudget` / `totalBudget`: قيم ميزانية العقد الإجمالية وحصة المقاول والمطور.

### ب. قطاعات التشطيبات الفرعية (Sub-Sectors)
مصفوفة تضم 8 قطاعات رئيسية للتشطيبات:
1. التأسيسات الكهروميكانيكية (7 بنود)
2. اللياسة والمعجون (5 بنود)
3. الجبس والجبس بورد (بندان)
4. الدهانات (بند واحد)
5. الأرضيات والرخام والبلاط (6 بنود)
6. الأبواب والألمنيوم (6 بنود)
7. الأعمال المعدنية (بند واحد)
8. العزل (بند واحد)

### ج. بنود أعمال العظم والتشطيبات (Items Breakdown)
- `structureItems`: تحتوي 29 بنداً تفصيلياً لأعمال العظم والأساسات (من الحفر والقواعد حتى بلاطة السطح والسترة)، مع تحديد نسبة الإنجاز `progress` من 0% إلى 100%.
- `finishingItems`: تحتوي 29 بنداً تفصيلياً لأعمال التشطيبات (السباكة، الكهرباء، التكييف، الجبس، الدهانات، البلاط، الأبواب، والمصاعد).

### د. جدول الدفعات المالية (`paymentsSchedule`)
يحتوي 9 مراحل تنفيذية روتينية، ويحسب لكل مرحلة:
- النسبة المئوية للدفعة (`ratio`).
- قيمة المقاول (`contractorVal`) وقيمة المطور (`devVal`).
- الحالة (`مدفوع` أو `غير مدفوع`) وتاريخ الاستحقاق.

## 📝 4. شرح نموذج المدخلات (`ProgressInputForm.jsx`)

يقدم هذا المكون شاشات إدخال سلسة مصممة بنظام الأكورديون (Accordion Sections) لتوفير المساحة وتسهيل تجربة المستخدم:

### الأقسام المطوية الداعمة للإدخال:
1. **بيانات وتفاصيل المشروع:** تعديل الاسم، الكود، التواريخ، والميزانيات.
2. **القطاعات الفرعية للتشطيبات (8 قطاعات):** شريط منزلق (Slider) أو مدخل رقمي لتعديل إنجاز القطاع.
3. **أعمال العظم (29 بنداً):** إمكانية إدخال نسبة الإنجاز لكل بند بنقرة واحدة، مع تمييز البنود المكتملة 100% باللون الأخضر.
4. **أعمال التشطيبات (29 بنداً):** تعديل نسب إنجاز بنود التشطيبات الداخلي والخارجي.
5. **جدول الدفعات والمستحقات:** تعديل قيم وتواريخ وحالات استحقاق الدفعات الـ 9.
6. **التوثيق المصور:** دعم رفع صور مباشرة من جهاز المستخدم، تحويلها إلى صيغة Base64 للعرض الفوري وإمكانية كتابة تعليق (Caption) على كل صورة أو حذفها.

## 🖨️ 5. لوحة المعاينة ومحرك التصدير (`ProgressDashboard.jsx`)

هذا المكون يمثل التقرير التنفيذي المنسق والذي يتم طباعته أو تصديره إلى PDF.

### الأقسام الثمانية المطبوعة في التقرير:
1. **الترويسة الرسمية:** شعار المشروع، اسم المشروع، الكود المرجعي، وتاريخ التقرير.
2. **ملخص المؤشرات:** كروت إحصائية تعرض إجمالي نسبة إنجاز العظم، إجمالي نسبة إنجاز التشطيبات، والنسبة الكلية للمشروع.
3. **الرسم البياني الدائري والشريطي:** تمثيل مالي ورسم بياني لتقدم الأعمال.
4. **جدول قطاعات التشطيبات الـ 8:** جدول ملخص بنسب إنجاز القطاعات.
5. **جدول بنود الأعمال التفصيلية (العظم والتشطيبات):** كشف كامل بالـ 58 بنداً مقارناً بالنسبي المئوية.
6. **جدول الدفعات المالية الـ 9:** يعرض الدفعات المسددة والمستقبلية.
7. **المعرض المصور:** شبكة صور تعكس الوضع الفعلي في الموقع.
8. **توقيعات الاعتماد:** مخصص لتوقيع الاستشاري، المطور، والمقاول الرئيسي.

### محرك التصدير لـ PDF والصور:
يستعمل المكون مكتبة `html2canvas` للالتقاط الرقمي للواجهة ومكتبة `jspdf` لتحويلها إلى ملف PDF:

```javascript
// آلية التصدير المطبقة داخل ProgressDashboard.jsx
const handleExportPDF = async () => {
  const element = dashboardRef.current;
  const canvas = await html2canvas(element, { scale: 2, useCORS: true });
  const imgData = canvas.toDataURL('image/png');
  const pdf = new jsPDF('p', 'mm', 'a4');
  const imgWidth = 210;
  const pageHeight = 295;
  const imgHeight = (canvas.height * imgWidth) / canvas.width;
  let heightLeft = imgHeight;
  let position = 0;

  pdf.addImage(imgData, 'PNG', 0, position, imgWidth, imgHeight);
  heightLeft -= pageHeight;

  while (heightLeft >= 0) {
    position = heightLeft - imgHeight;
    pdf.addPage();
    pdf.addImage(imgData, 'PNG', 0, position, imgWidth, imgHeight);
    heightLeft -= pageHeight;
  }
  pdf.save(`تقرير_إنجاز_${data.projectNumber}.pdf`);
};
```

## 🧮 6. المعادلة الرياضية لحساب نسبة الإنجاز العامة

تُحسب نسبة الإنجاز الكلية للمشروع بناءً على معادلة أوزان متوازنة:

$$\text{نسبة العظم الكلية} = \frac{\sum \text{نسب بنود العظم (29 بنداً)}}{29}$$

$$\text{نسبة التشطيبات الكلية} = \frac{\sum \text{نسب بنود التشطيبات (29 بنداً)}}{29}$$

$$\text{نسبة إنجاز المشروع الإجمالية} = (\text{نسبة العظم} \times 50\%) + (\text{نسبة التشطيبات} \times 50\%)$$

## 🛠️ 7. دليل حل المشاكل والتطوير المستقبلي (Troubleshooting)

| المشكلة | السبب المحتمل | الحل البرمجي المناسب |
| :--- | :--- | :--- |
| **ظهور قيمة `NaN%` في التقرير** | إدخال قيمة نصية بدلاً من رقم في أحد البنود | التأكد من استخدام `parseFloat(val) \|\| 0` عند تحديث الحالة في `ProgressInputForm.jsx` |
| **اقتطاع أسفل التقرير عند التصدير لـ PDF** | عدم ضبط الارتفاع الديناميكي للمحتوى المتعدد الصفحات | استخدام الحلقة التكرارية `while (heightLeft >= 0)` في `jsPDF` لإضافة صفحات تلقائياً |
| **بطء واجهة التقرير عند رفع صور متعددة** | أحجام الصور المرفوعة كبيرة جداً وتملأ ذاكرة الرام | دمج `imageOptimizer` لضغط وتصغير أبعاد الصورة قبل تحويلها لـ Base64 |
| **عدم ظهور الخطوط العربية بوضوح في الـ PDF** | عدم تعيين خيار `useCORS` في `html2canvas` | تأكيد خيار `{ scale: 2, useCORS: true }` عند استدعاء `html2canvas` |

---

## 🚀 8. خطوات الاستخدام في مشروع جديد

1. قم بنسخ مجلد `frontend/src/components/completion` إلى مشروعك جديد.
2. قم بنسخ وتوجيه الصفحة `frontend/src/pages/CompletionPercentagePage.jsx`.
3. تثبيت التبعيات الضرورية: `npm install html2canvas jspdf framer-motion lucide-react`.
4. ربط الصفحة بمحرك التوجيه (React Router) تحت المسار المحمي `/completion-percentage`.
