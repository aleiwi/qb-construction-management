**الإصدار:** 1.0 — **التاريخ:** أغسطس 2026

## 1. الوضع الحالي (أثبته فحص الكود)

### ما يعمل الآن
| المرحلة | الحالة | الدقة الحالية |
|---------|--------|---------------|
| استخراج DXF/DWG | ✅ يعمل (ezdxf) | يقرأ: LINE/POLYLINE/LWPOLYLINE/CIRCLE/ARC/SPLINE/ELLIPSE/INSERT/HATCH/DIMENSION |
| التجميع بالطبقات | ✅ يعمل | تجميع الكيانات حسب layer |
| التصنيف التلقائي | ✅ يعمل | 4 أولويات: طبقة مطابقة → كلمة مفتاحية → نص → هندسة |
| محرك الكميات | ✅ يعمل | 11 نوع عنصر بمعادلات + تقدير حديد |
| التعلم الذاتي | ✅ يعمل | يحفظ التصنيفات اليدوية (auto_learner) |
| قاعدة الأسعار | ✅ يعمل | أسعار سوقية سعودية + ربط تلقائي |
| الملخص والتصدير | ✅ يعمل | Excel/PDF + تقارير مقارنة |

### نقاط الضعف المعروفة (من قراءة الكود)
1. ✅ **حُلّت القيم الافتراضية**: النظام الآن يقرأ الأبعاد الحقيقية من نصوص (H/T/W/D) وقياسات DIMENSION ويحول وحدات الرسم إلى أمتار — الافتراضيات (3م/20سم) تُستخدم فقط كملاذ أخير.
2. **لا يوجد قياس يدوي على الشاشة** — كل شيء تلقائي، والمهندس لا يستطيع "رسم" عنصرًا يدويًا.
3. **لا يوجد كشف للفتحات في الجدران** (النوافذ/الأبواب تُحسب كطبقات منفصلة فقط، لا تُخصم من الجدار).
4. **التصنيف الهندسي ضعيف**: القواعد الهندسية الأخيرة (أولوية 4) تعتمد فقط على المساحة/الطول بدون شكل (مستطيل ≠ دائرة ≠ L-shape).
5. ✅ **حُلّ قياس الدقة الشامل**: منصة قياس + 10,000 مخطط → تصنيف 100% / كميات 0.0% (انظر `BENCHMARK_ACCURACY_REPORT.md`).
6. **INSERT (الكتل) غير مدروس جيدًا**: كتل الأبواب/النوافذ تحتاج فكّ وتكرار لحساب العدد الصحيح.

## 4. منهجية قياس الدقة (جاري التنفيذ الآن)

### المبدأ
لا يمكن تحسين ما لا يُقاس. نبني **مخططات مرجعية** (ground truth) بقيم معروفة، ثم نمررها على النظام ونقارن.

### أنواع الاختبار
1. **مخططات اصطناعية** (مولّدة برمجيًا): كل مخطط يعرف محتواه بدقة (عدد الجدران، أبعادها، أنواعها) — يختبر الاستخراج والتصنيف والكميات.
2. **مخططات حقيقية** (قيد التجميع من مصادر مفتوحة): اختبار على أرض الواقع.
3. **تشويش واقعي**: أسماء طبقات غير معيارية، دوائر ديكورية، نصوص عربية، ملفات تالفة.

### مقاييس الدقة
| المقياس | التعريف |
|---------|---------|
| تصنيف صحيح | نسبة العناصر المصنفة بالنوع الصحيح |
| خطأ الكمية | \|كمية النظام − الكمية الحقيقية\| / الكمية الحقيقية |
| عناصر مفقودة | عناصر في الرسم لم تُستخرج |
| عناصر زائفة | عناصر مستخرجة غير موجودة فعلًا |
| وقت المعالجة | ثوانٍ لكل مخطط |

### الهدف
- تصنيف ≥ 90%
- خطأ كمية ≤ 5% على المخططات النظيفة
- خطأ كمية ≤ 15% على المخططات الواقعية
