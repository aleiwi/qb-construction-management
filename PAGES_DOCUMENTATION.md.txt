# 🏗️ Quantum Build — Complete Pages Documentation

> **Version:** 3.0.0 — Enterprise Edition  
> **Last Updated:** 2026-07-27  
> **Status:** ✅ Production-Ready ERP System

Quantum Build is an advanced, AI-integrated construction project management and cost estimation ERP system. This document provides a thorough, professional reference for every page and major component in the frontend application — covering their purpose, UI structure, data dependencies, and integration points.

---

## 🛠️ Architecture & Technology Stack

| Layer | Technology |
|---|---|
| **UI Framework** | React 18 + Vite |
| **Styling** | Tailwind CSS + custom dark/light theme system |
| **Animations** | Framer Motion |
| **Data Fetching** | TanStack React Query (`@tanstack/react-query`) |
| **Charts & Graphs** | Recharts (PieChart, BarChart, RadarChart, etc.) |
| **PDF Export** | jsPDF + html2canvas |
| **Auth & Database** | Supabase (PostgreSQL + Auth + Row Level Security) |
| **Backend API** | FastAPI (Python, `uvicorn`) |
| **Voice & AI** | Web Speech API (`SpeechRecognition` / `SpeechSynthesis`) |
| **Error Handling** | Custom Error Boundaries per module |
| **Lazy Loading** | React `Suspense` + dynamic imports |

### 9. Smart Engineering Cost Calculator
**File:** [CalculatorWizard.jsx](file:///d:/prog/QB/frontend/src/components/calculator/CalculatorWizard.jsx)  
**Route:** `/calculator` or embedded in `/project/:id/edit`  
**Auth Required:** ✅ Protected

**Purpose:**  
A sophisticated multi-step (wizard-style) cost estimation engine for construction projects. Provides engineers with granular, itemized cost breakdowns across all construction disciplines.

**Wizard Steps / Stages:**
1. **Project Dimensions** — Floor area, number of floors, height parameters.
2. **Concrete Works** — Slab, columns, and beam volume calculations.
3. **Rebar / Steel Works** — Reinforcement tonnage estimation.
4. **Masonry & Walls** — Block quantities and mortar volumes.
5. **Waterproofing & Insulation** — Surface area treatment costs.
6. **Plumbing & Sanitary** — Pipe runs, fixtures, drainage.
7. **Electrical Works** — Wiring, panels, conduit, lighting.
8. **Finishing & Fit-out** — Flooring, plastering, tiling, painting.

**UI Features:**
- Step-by-step progress indicator (NavigationBar).
- Editable unit price fields per line item.
- **Live Results Summary:** Itemized cost table updating in real time as inputs change.
- **Profit Margin & VAT Configurator:** Apply percentage-based markups to the base cost.
- **PDF Export:** Full cost estimate exportable as a professional PDF document.

**Sub-components:**
- `CalculatorItemsTable.jsx` — Editable BOM (Bill of Materials) table
- `CalculatorResults.jsx` — Final cost summary report
- `ProjectSettings.jsx` — Project metadata for the estimate
- `AdvancedEngineeringStandards.jsx` — Regional/international code references
- `useCalculatorEngine.js` — Core computational logic (custom React hook)

**Migration Note:**
- The entire `components/calculator/` folder must be migrated together to preserve mathematical integrity.

### 23. Completion Percentage Report Page
**File:** [CompletionPercentagePage.jsx](file:///d:/prog/QB/frontend/src/pages/CompletionPercentagePage.jsx)  
**Route:** `/completion-percentage`  
**Auth Required:** ✅ Protected

**Purpose:**  
A specialized, formal report generation module for producing official construction completion percentage certificates — the industry-standard document used to justify payment certificates, milestone verification, and client reporting.

**Architecture:**  
The page uses a **two-panel split layout** (`lg:grid-cols-12` → 5 + 7 columns):

**Left Panel — Data Input** *(ProgressInputForm)*:
- Project header info: Project name, client, site location, report date, report number.
- **Structural Works Accordion:** Individual progress sliders (0–100%) for each structural item (Excavation, Foundations, Columns, Beams, Slabs, etc.).
- **Finishing Works Accordion:** Progress sliders for finishing trades (Plastering, Tiling, Painting, MEP, etc.).
- **Sub-sector / Discipline Breakdown:** Named sub-sectors each with individual progress percentages for radar chart visualization.
- **Financial Summary Fields:** Total Budget, Amount Spent.
- **Photos Section:** Upload field site photos per section.
- **Notes & Recommendations Field:** Free-text observations.

**Right Panel — Live Preview** *(ProgressDashboard)*:
- **Overall Progress Ring** *(Recharts PieChart)*: Animated donut showing global completion %.
- **Structural vs. Finishing Split:** Two separate progress bars with color-coded percentages.
- **Discipline Radar Chart** *(Recharts RadarChart)*: Multi-axis radar showing balance across trades.
- **Task Status Distribution Chart** *(Recharts BarChart)*: Completed / In Progress / Not Started counts.
- **Budget Utilization Bar:** Visual spend vs. budget gauge.
- **Item Filter Tabs:** All / Structure / Finishing — with search and status filter dropdowns.
- **Detailed Items Table:** Each work item listed with its progress bar, status badge, and notes.
- **Photo Gallery Lightbox:** Full-screen photo viewer with navigation.
- **PDF Export Button:** Generates a print-ready, professionally formatted completion certificate using `html2canvas` + `jsPDF`.
- **Print Button:** Direct browser print trigger.

**Sub-components:**
- [ProgressInputForm.jsx](file:///d:/prog/QB/frontend/src/components/completion/ProgressInputForm.jsx) — Left panel input accordion
- [ProgressDashboard.jsx](file:///d:/prog/QB/frontend/src/components/completion/ProgressDashboard.jsx) — Right panel live preview and export engine
- [defaultCompletionData.js](file:///d:/prog/QB/frontend/src/components/completion/defaultCompletionData.js) — Pre-populated demo dataset

**Calculation Logic** *(inside ProgressDashboard)*:
```
Structural Progress  = Average(all structureItems[].progress)
Finishing Progress   = Average(all finishingItems[].progress)
Overall Progress     = (Structural Progress + Finishing Progress) / 2
Budget Spent %       = (spentBudget / totalBudget) x 100
Remaining Budget     = max(0, totalBudget - spentBudget)
```

**State Management:** All data is held in a single `completionData` state object in the parent page, passed as props to both child components. Changes in `ProgressInputForm` are propagated up via `onChange` callback, triggering a live re-render of `ProgressDashboard`.

## 🔒 Route Protection Architecture

All protected pages are wrapped with `<ProtectedRoute>` in [App.jsx](file:///d:/prog/QB/frontend/src/App.jsx). Critical heavy pages also use lazy loading with `React.Suspense`:

```jsx
// Public Route Example
<Route path="/login" element={
  <ErrorBoundary>
    <LoginPage />
  </ErrorBoundary>
} />

// Protected + Lazy-Loaded Route Example
<Route path="/dashboard" element={
  <ProtectedRoute>
    <DashboardErrorBoundary>
      <Suspense fallback={<SmartLoader message="Loading Dashboard..." />}>
        <LazyDashboard />
      </Suspense>
    </DashboardErrorBoundary>
  </ProtectedRoute>
} />
```

## 🚀 Migration Guide

To transplant any page into a new project:

1. **Copy the page file** and all component sub-folders it imports from.
2. **Install dependencies** listed above via `npm install`.
3. **Configure backend connection:** Edit the service files in `frontend/src/services/` to point to your new API or Supabase instance.
4. **Set environment variables:** Copy `.env` and populate `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
5. **Configure Tailwind:** Ensure `tailwind.config.js` includes the dark mode class strategy (`class`) and the Arabic font (e.g., `Cairo`, `Tajawal`) is imported via Google Fonts.
6. **Register routes:** Add each page to your `App.jsx` router, wrapping protected pages with your authentication guard component.
