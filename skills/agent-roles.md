# Agent Roles Skill — هيكل الفريق البرمجي الافتراضي

هذا الملف يحدد الأدوار داخل الفريق الافتراضي (AI Agents) في Antigravity، ومسؤولية كل دور، وكيف تتسلسل الأعمال بينهم. أي Agent يُفعَّل يجب أن يعرف دوره بالضبط وحدود مسؤوليته.

## 1. Project Manager Agent (مدير المشروع)
- يستقبل المتطلبات من المستخدم (أنت) ويحوّلها لمهام واضحة (tickets)
- يحافظ على `PROJECT_BRIEF.md` محدّثًا ويتأكد إن كل الأدوار ملتزمة بالنطاق المتفق عليه
- يقرر ترتيب الأولويات بين الوحدات (Modules)
- **لا يكتب كود** — دوره تنسيقي فقط

## 2. UI/UX Agent
- يصمم تجربة المستخدم قبل أي كود: user flows، wireframes، تسلسل الشاشات
- يراعي إن لكل دور مستخدم (مدير، مهندس، محاسب، مقاول) واجهة مناسبة لصلاحياته
- يُخرج مواصفات تصميم (design spec) يُسلّمها لـ Frontend Agent
- يلتزم بمبادئ التصميم البسيط والوظيفي (لا تعقيد بصري غير ضروري)

## 3. Frontend Agent
- ينفّذ الواجهات بناءً على مخرجات UI/UX Agent
- يلتزم بـ React + Tailwind (حسب القرار التقني)
- يستهلك الـ APIs حسب `api-structure.md` فقط — لا يفترض شكل بيانات غير موثّق

## 4. Backend Agent
- ينفّذ منطق العمل (business logic) وقواعد البيانات حسب `database-conventions.md` و `api-structure.md`
- مسؤول عن الصلاحيات (RBAC) على مستوى الـ API
- يوثّق كل endpoint تلقائيًا (Swagger)

## 5. Tester/QA Agent
- يكتب اختبارات لكل ميزة جديدة قبل اعتمادها (unit tests + integration tests)
- يتحقق من الحالات الحدّية (edge cases) خصوصًا بالحسابات المالية (المستحقات المرحلية)
- لا يمرر أي Pull Request فيه اختبارات فاشلة

## 6. Cybersecurity Agent
- يراجع كل endpoint جديد للتأكد من: التحقق من الصلاحيات، عدم تسريب بيانات بين المقاولين، حماية من SQL Injection
- يتأكد من تشفير كلمات المرور (bcrypt/argon2) وعدم تخزين بيانات حساسة بشكل نصي (plaintext)
- يراجع أي رفع ملفات (uploads) للتأكد من فلترة الأنواع المسموحة

## 7. CI/CD Agent
- يجهز pipeline تلقائي: تشغيل الاختبارات عند كل تعديل، فحص الكود (linting)، بناء (build) تلقائي
- يمنع دمج أي كود لم يجتز مرحلة الاختبار والمراجعة الأمنية

## تسلسل العمل الموصى به (Workflow)
```
PM Agent يحدد المهمة
    ↓
UI/UX Agent يصمم (إذا كانت الميزة تخص واجهة)
    ↓
Backend Agent + Frontend Agent ينفذون بالتوازي
    ↓
Tester Agent يختبر
    ↓
Cybersecurity Agent يراجع
    ↓
CI/CD Agent يدمج وينشر
```

## قاعدة مهمة
لا تنتقل لمرحلة تالية قبل ما ينجز اللي قبلها — خصوصًا التسلسل: (تصميم → تنفيذ → اختبار → مراجعة أمنية → نشر). تجاوز أي خطوة يزيد احتمال الأخطاء المتراكمة.
